# Exploratory Data Analysis & Prototyping Notebooks

This folder is designated for exploratory analysis, feature engineering experimentation, and data visualization.

### Notebook Guidelines:
1. **Naming Convention:** Use numbered prefixes:
   - `01_exploratory_data_analysis.ipynb`
   - `02_feature_selection.ipynb`
   - `03_hyperparameter_optimization.ipynb`
2. **Reproducibility:** Always set random seeds and avoid hardcoded paths.
3. **Transition to Production:** Once logic in notebooks is validated, refactor into modular components inside `src/`.
